# Советы от Газпромбанка

Статическая HTML-страница с подборкой советов в виде карточек. Вёрстка включает шапку, хлебные крошки и подвал.

<!-- ![Скриншот проекта](./docs/screenshot.png) -->

## Быстрый старт

Сборки и команды запуска в проекте нет. Откройте `advice.html` в браузере.

## Стек

- HTML — страница `advice.html`.
- CSS — стили разделены на общие правила (`css/global/`) и блоки (`css/blocks/`).
- Noto Sans — локальные файлы шрифтов в форматах WOFF и WOFF2.
- Изображения и SVG-иконки — каталог `images/`.

SCSS с partials `_variables` / `_settings`, vanilla JS и `sprite.svg` в текущей структуре файлов отсутствуют — их наличие требует уточнения.

## Возможности страницы

- Сетка из восьми карточек с советами о льготах, кредитном рейтинге, золоте, налоговом вычете, переводах через СБП и других темах.
- Шапка с логотипом и визуальным элементом меню.
- Хлебные крошки.
- Подвал с телефонами, значками App Store и Google Play и датой информации.
- Локальные начертания Noto Sans: Regular, Medium и Bold.

## Структура проекта

```text
.
├── advice.html
├── css/
│   ├── blocks/       # Стили шапки, карточек, хлебных крошек, контента и подвала
│   ├── global/       # Шрифты, базовые стили и контейнер
│   └── style.css     # Подключение таблиц стилей
├── fonts/            # Noto Sans в WOFF и WOFF2
├── images/           # Иллюстрации, логотипы и SVG-иконки
└── LICENSE
```
